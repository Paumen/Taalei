# Referentie: 16 paren met het antwoord erbij

Per blad twee uitvoeringen van hetzelfde objecttype, met erbij welke de goede stijl is. Geen kit- of assetnamen: de afgekeurde kant komt vrijwel altijd uit een bronkit, dus met namen erbij leer je de herkomst herkennen in plaats van de stijl. De goede kant staat per blad geloot boven of onder.

De zestien: pillar, bench, potion, key, chest, bucket, tree-pine, skull,
patch-grass, door, crate, axe, saw, candle, shelf, tree.
